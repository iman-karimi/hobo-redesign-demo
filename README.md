# HOBO Computer Services — Unofficial Redesign Concept

This is a demo redesign concept, not the official HOBO Computer Services website.

## Run locally
1. Install Node.js 20+
2. Open this folder in a terminal
3. Run:
   npm install
   npm run dev
4. Open http://localhost:3000

## Deploy to Vercel
- Create a GitHub repository and upload this project.
- Import the repository into Vercel.
- Vercel should detect Next.js automatically.
- Click Deploy.

## Verified source content used
Publicly listed services and contact information were taken from the current HOBO Computer Services website. Marketing claims, customer counts, testimonials, and business hours from the visual mockup were deliberately excluded because they were not verified.

## Before any real client use
Get the business owner's approval for branding, logo use, content, contact forms, analytics, privacy policy, and publication.
